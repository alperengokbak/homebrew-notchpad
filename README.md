# Homebrew tap for Notchpad

[Notchpad](https://github.com/alperengokbak/notchpad) turns the notch on a Mac into a small panel.

```bash
brew install --cask alperengokbak/notchpad/notchpad
```

Update with `brew upgrade --cask notchpad`, remove with `brew uninstall --cask notchpad`.

The first time you open it, macOS asks you to allow it in System Settings → Privacy & Security ("Open Anyway"), because the app isn't notarised by Apple.
